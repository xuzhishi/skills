# 会议记录模板

> 用途：本文件是「会议记录归档」的标准模板。生成文档时用实际数据替换 `{{占位符}}`，并严格遵守下方的格式规范。标「可选」的区块若无数据可省略，并在汇报中说明。

## 命名规则

目录结构（三级）：

```
会议纪要/
└── YYYY-MM-DD/                        ← 日期目录
    └── HH:MM-HH:MM 会议主题            ← 实际时间 + 会议名
```

示例：`10:00-10:30 产品周会`（时间用实际起止，非预定）

- 主题取智能纪要开头的「会议主题」字段（比 meeting get 的 subject 更具体）
- 文档头部的「会议主题」字段只写智能纪要给出的主题名，不拼接 subject 前缀

## 格式规范速查

| 元素 | 语法 |
| --- | --- |
| 高亮 | `==文字==` |
| 加粗 | `**文字**` |
| 斜体 | `*文字*` |
| 行内代码 | `` `代码` `` |
| 引用块 | `> 文字`（多行引用每行一个 `>`） |
| 水平分隔线 | `---` |
| 无序列表 | `- 项目`（项与项之间加空行） |
| 表格 | markdown 表格 |

## 注意事项

- 没有数据的内容不要编造，标注「未获取」
- 转写段落多时（几十段），用脚本解析 CLI 的 JSON 输出，避免手抄出错
- 高亮要克制：风险、时间节点、关键决策才高亮，不要整段全亮
- 转写原话保持原样，包括口语化表达和语气词，不要润色
